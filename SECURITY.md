# Güvenlik politikası

Güvenlik açığı bildirimlerini herkese açık issue içinde ayrıntılandırmayın.

GitHub deposundaki **Security → Report a vulnerability** seçeneğini kullanın. Özel bildirim özelliği kullanılamıyorsa, teknik ayrıntı paylaşmadan depo sahibinden özel iletişim kanalı isteyen kısa bir issue açın.

Bildirimde mümkünse şunları ekleyin:

- Etkilenen sürüm
- Tarayıcı ve işletim sistemi
- Sorunu yeniden üretme adımları
- Beklenen ve gözlenen davranış
- Varsa örnek playlist türü

API anahtarlarını, hesap bilgilerini veya kişisel verileri rapora eklemeyin.
